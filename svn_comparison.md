# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветки создаются практически мгновенно и не требуют копирования всего проекта.
В SVN ветвление связано с копированием директорий в централизованном репозитории,
поэтому этот процесс менее удобный и больше зависит от сервера.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN является централизованной системой контроля версий.
Для коммита требуется соединение с центральным сервером.
В Git коммиты можно создавать локально без доступа к интернету.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в старых legacy-проектах и организациях,
где уже существует централизованная инфраструктура.
Например, в некоторых государственных и банковских системах.
